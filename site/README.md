# Azkarify Android privacy policy site

`android/policy.html` is the English and Arabic policy shown at
`https://azkarify.saeed.sh/android/policy`. Vercel serves it from the
`azkarify-policy` project with `cleanUrls` enabled by `vercel.json`.

Update the policy and republish this directory when the Android app changes
what data it sends off the device. The page describes the country and city
catalog's request data and Play Integrity proof.
