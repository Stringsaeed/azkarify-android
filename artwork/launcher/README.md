# Azkarify launcher icon

AI-generated ivory crescent with three satin-gold olive leaves on forest green
`#143E35`. The transparent source is `azkarify-crescent-olive.png`.

Imported using Android Studio Asset Studio as adaptive and legacy launcher icons.
Foreground and monochrome layers use 70% scaling without trimming. Outputs include
five density variants, adaptive regular/round icons, a themed monochrome layer,
and the 512px Play Store image at `app/src/main/ic_launcher_azkarify-playstore.png`.
The app manifest uses `ic_launcher_azkarify` and `ic_launcher_azkarify_round`.
The previous shared iOS launcher resources remain available.
